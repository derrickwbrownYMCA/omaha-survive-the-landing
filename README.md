# Omaha: Survive the Landing

A browser-based, first-person historical survival game prototype set during the Normandy landings.

## Play

Once GitHub Pages is enabled under **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**. The game will be available at:

https://derrickwbrownYMCA.github.io/omaha-survive-the-landing/

## Current version

v3.3: beach and ocean graphics pass, 100-soldier target, procedural character models, survival gameplay, and experimental audio.

## Controls

WASD: move · Mouse: look · Shift: sprint · C: crouch · E: assist · R: field dressing · Esc: pause.

## Notes

This is an experimental build. Graphics and sound performance vary by browser and device. The game loads Three.js from an external CDN and requires an internet connection.

Future updates can be committed to this repository without sending ZIP files.
