# Omaha: Survive the Landing

A browser-based first-person survival prototype inspired by the Normandy landings.

## Play
https://derrickwbrownYMCA.github.io/omaha-survive-the-landing/

Enable GitHub Pages at Settings → Pages → Deploy from a branch → main / (root) if it isn't live yet.

## Current build: v3.4
- Directional bullet near-miss cracks and whizzes tied to projectile paths; cover-impact feedback.
- Wind-formed ripples and shallow dune relief on the beach mesh.
- Additional ocean swells and moving breaker crests, retaining shoreline foam.
- Target population: 100 soldiers. Experimental browser-generated audio, not recorded sound samples.

Controls: WASD movement, mouse look, Shift sprint, C crouch, E assist, R bandage, Esc pause.
Use TEST AUDIO if sound isn't playing. Chrome requires a user click to start audio.

The game depends on Three.js from an external CDN. The new features have been statically checked but not verified in a live interactive playtest.
